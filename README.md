# Riftcards

A collection and trading app for Riftbound TCG players. Track your cards in binders, post sale and trade listings, and discover other players.

## Tech Stack

- **Expo** & **React Native** (TypeScript) — iOS and Android
- **Expo Router** — navigation
- **Supabase** — database, authentication, Row Level Security
- **TanStack Query** — data fetching and caching
- **i18next** — English / Turkish localization
- **Reanimated** — animations
- **OpenRift API** — card catalog

## Getting Started

```bash
npm install
npx expo start
```

Card data provided by [OpenRift](https://openrift.app). Riftbound and all card images are property of Riot Games.
